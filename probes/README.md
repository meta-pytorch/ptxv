# Hardware probes for assumptions

Each directory is a tiny kernel that answers one question about GB300 behavior that the
model depends on (ASSUMPTIONS.md). Run them with

```bash
ptxv probe probes/<name>        # each variant once, on a free GPU, under a watchdog
```

When the simulator models the probed behavior, the probe's variants also carry an `expect`
verdict, and `cargo test` checks that the model agrees with the recorded hardware result.
