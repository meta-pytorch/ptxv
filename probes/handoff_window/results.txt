probes/handoff_window on GB300 (CUDA 13.0), 2026-11-10. One GPU per job (two for the 2-GPU
kernel), clusters of 2 unless noted, 256 threads per CTA, 2e4 rounds per cluster per launch.
Counts: failures / hand-offs. 95% limits: exact Poisson for k < 50; 3/N for k = 0.
Levers: "co-tenant" = a kernel storing into the peer CTA's shared memory inside its own 2-CTA
clusters (mode 1), either on another stream of the same process ("in-process") or in another
client process of a private MPS daemon ("MPS"); "x3" = 3 co-tenant CTAs per SM (COT_MULT=3),
else 1. "same-CTA stores" = threads 32+ of the hand-off CTAs store into the peer's scratch
(noise 1; noise 5 = producer CTA only, 4 = consumer CTA only, 3 = remote loads instead,
2 = local shared loads/stores instead). "unmodified" = the hand-off CTAs run only the hand-off.
The producer path is straight-line code per variant (template instance).
